HƯỚNG DẪN THÊM QR CODE
======================

1. Đặt file QR code vào thư mục này
2. Đặt tên file: qr-code.png (hoặc .jpg)
3. Hoặc sửa đường dẫn trong script.js (dòng có "assets/qr/qr-code.png")

Kích thước QR code đề xuất: 200x200px hoặc lớn hơn

File sẽ được hiển thị trong mystery box đặc biệt!
