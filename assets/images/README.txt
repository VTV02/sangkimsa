HƯỚNG DẪN THÊM HÌNH ẢNH VÀ VIDEO
================================

1. Đặt các file hình ảnh và video vào thư mục này:
   - Hình ảnh: .jpg, .jpeg, .png, .gif
   - Video: .mp4, .webm, .ogg

2. Mở file script.js và tìm mảng galleryItems (khoảng dòng 427)

3. Thêm đường dẫn các file của bạn, ví dụ:
   
   const galleryItems = [
       'assets/images/photo1.jpg',
       'assets/images/photo2.jpg',
       'assets/images/video1.mp4',
       // Thêm các file khác...
   ];

4. Lưu file và mở lại index.html trong trình duyệt

Lưu ý: Tên file không nên có khoảng trắng, dấu tiếng Việt có dấu
